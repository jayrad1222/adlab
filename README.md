# Ad Lab

A Claude Code plugin for Scaling Skool members: decode your market from the public ad libraries, build buying-situation personas, get interrogated like a behavioural-science strategist would, and leave with an evidence-backed ad bank and a finance-gated test plan.

Start with [START-HERE.md](START-HERE.md). Install with [INSTALL.md](INSTALL.md). Rules in [LEGAL-AND-ETHICS.md](LEGAL-AND-ETHICS.md). Design packet in [docs/design/](docs/design/).

```
/plugin marketplace add jayrad1222/adlab
/plugin install adlab@adlab
/adlab:setup
/adlab:start
```
