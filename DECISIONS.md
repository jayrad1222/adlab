# Decisions log

Dated, in order. Each entry: what was decided, why, what it affects.

- **2026-10-22 · Build runs here, on Fable 5.1, not in a separate Opus 5.5 session.** Jared chose "do this task here". The spec in `docs/design/02-OPUS-5.5-BUILD-PROMPT.md` is followed as written; effort guidance for subagents (medium for library writing, low for per-ad analysis) is kept.
- **2026-10-22 · Repo location.** Ad Lab is its own git repository, separate from the community's other work. No push until Jared says so.
- **2026-10-22 · Python floor is 3.9.** The reference Mac runs 3.9.6 as the system Python. Tools avoid 3.10+ syntax (`match`, `X | Y` unions at runtime).
- **2026-10-22 · Transcription.** `mlx-whisper` on Apple Silicon (this Mac is arm64), `faster-whisper` elsewhere; both optional, installed by `setup.py` only when the member opts in, because the model download is large.
- **2026-10-22 · Venv location.** `${CLAUDE_PLUGIN_DATA}/venv` when that variable is set (plugin installs), else `~/.adlab/venv` (`--plugin-dir` and development). Chromium goes wherever Playwright puts it for that venv.
- **2026-10-22 · Member data.** `./adlab-workspace/` in the project the member opened Claude Code in; `clients/<name>/` under it for service providers.
- **2026-10-22 · Pull manners.** Read-only, no login, one search at a time, 2 to 4 second pauses, desktop user agent, default caps 40 ads per advertiser and 8 advertisers. Media downloaded immediately because CDN URLs expire.
- **2026-10-22 · Template defaults are white, not cream.** The build prompt lists cream and off-white page backgrounds among the styles to avoid; the first demo used a cream default, so the default `bg` is now `#ffffff`. Members set their own in `business/brand.json`.
- **2026-10-22 · Example runs keep text only for competitor ads.** Competitor creatives, cards and frames stay out of the repo (gitignored under `examples/**/ads/`); the examples reference the public library pages by link. The member's own renders are kept.
- **2026-10-22 · Example run B is the minimalist-wallet category with Ridge as the stand-in member business.** Jared did not name a product brand; Ridge was chosen because its category has several active, public advertisers (Ekster, Bellroy, Secrid, Andar) and clear angles. Everything about it is observed from public pages; nothing is owner-provided.
- **2026-10-23 · Skill pre-approval lists both quoted and unquoted tool paths.** A `claude --plugin-dir ./ -p "/adlab:doctor --quick"` smoke test showed the model quoting `${CLAUDE_PLUGIN_ROOT}` (this Mac's path has a space), which missed the unquoted `allowed-tools` pattern and stalled on an approval prompt in non-interactive mode. Both forms are now listed; the rerun executed without a prompt.
- **2026-10-23 · `ad.md` is written by a tool, not a subagent.** `tools/admd.py` writes the reading sheet deterministically (copy, dates, variants, frames, transcript, landing summary, an honest coverage ceiling); subagents only add shot lists for videos. Cheaper and consistent.
- **2026-10-23 · EU transparency capture is best effort and unverified.** `meta_pull.py --eu-details` looks for Meta's `aaa_info` payload on the ad detail page. On the ads probed (a Bellroy ad and ten from each example run) no such payload appeared and no EU section was visible, consistent with ads that never delivered in the EU. The field stays in the schema as `eu: null` until a run captures one; the docs say so.
