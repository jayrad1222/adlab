# Test counterintuitive things (Rory Sutherland, Alchemy, 2019)

## The idea in three sentences
Sutherland's rule is to test counterintuitive things only because no one else will: the logical test has already been run by every competitor, so its result is priced in, while the counterintuitive test is the cheapest uncontested experiment available. The point is not that odd ideas are usually right, it is that when they are right nobody else has found out yet. In Ad Lab, every angle set should contain at least one test that the business owner's first instinct is to reject.

## Spot it in a competitor ad
- An ad that should not work by category logic and is still running. Example: a 90-second static text ad in a video-first niche, live for four months.
- A claim that undercuts the obvious benefit. Example: "this will take longer than you want it to."
- A format nobody else in the market map uses. Example: a screenshot of a bad review with a reply.
- Pricing or offer structures that break the category pattern. Example: pay what you want, or a deposit instead of a discount.
- Ads that target the "wrong" audience for the product. Example: a tool for freelancers advertised to the clients who hire them.
- Visuals that violate the brand's own style. Example: a premium brand running a deliberately ugly ad, if it has been live long enough to be a decision rather than an accident.

## Use it in ours
- Hook: write the line the owner says "we could never say that" about, and put it in the test set with a cap on spend.
- Body: keep the body conventional when the hook is counterintuitive, so the test isolates one variable.
- Static: one deliberately odd execution per batch (plain text, no product, a question with no answer), budget-capped.
- Video: test the founder saying the uncomfortable true thing about the category.
- Landing page: counterintuitive tests usually belong in the ad, not the page; keep the page stable so the ad test is readable.

## How it backfires
"Counterintuitive" is not a licence to be wrong. Each test needs a mechanism (why might this work, for whom) and a falsifier (what result would kill it) before it runs; the interrogation schema requires both. Some counterintuitive ideas are counterintuitive because they are policy violations or untrue; those are rejected, not tested. Small accounts cannot afford many losers, so the finance decision rules set the cap: usually one odd test per batch at a fixed share of spend. And a counterintuitive winner can be a fluke; the evidence integrity rubric asks for a replication before it enters the bank as a pattern.

## Questions it adds to the interrogation
- What is the one thing you would never say in an ad, and why not? Is the reason policy, truth or taste?
- Which idea did you reject fastest when planning your last campaign?
- What would you test if losing the money did not matter?
