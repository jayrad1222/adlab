# Research notes: what is true in October 2026

Compiled October 22, 2026 from official documentation where it could be read and from vendor or agency sources where it could not. Each section says which is which. Opus should re-verify anything marked "vendor" before hard-coding it.

## 1. Ad library data access

### Meta Ad Library

- **Official API:** covers social-issue, electoral and political ads, plus ads delivered in the EU and associated territories (the Transparency Center page says this; it was last updated in 2023). Political ads stay seven years; EU ads are archived one year after their last impression. The developer documentation page returned 404 and the API page returned 403 to an automated fetch, so field lists, rate limits and identity-verification steps were not confirmed from Meta directly. Vendor guides agree the API is not a route to general commercial ads outside the EU and UK and cite a rate limit of roughly 200 calls per hour per token; treat those as vendor claims.
- **Web UI without login:** Jared's October 21 run pulled 1,927 unique active ads with headless Playwright, a desktop user agent, one search at a time with 2 to 4 second pauses, no login, by reading the JSON embedded in the HTML and intercepting `/api/graphql/` responses. No login wall, captcha or block appeared. Some Page views stopped at 30 ads when Meta reported hundreds, because lazy loading did not always fire headless; treat per-Page counts as samples. Media CDN URLs expire, so download immediately. Keyword searches are noisy ("skool" matches Vans Old Skool).
- **The co-branded finding:** Skool's own Page runs "<Creator> with Skool" ads linking to each community's about page; 328 were collected. A creator's own Page can show zero ads while dozens run under Skool's Page. Any competitor roster in the creator or community category must search both.
- **EU transparency block:** for ads that also delivered in the EU, the ad detail page shows reach and a breakdown by age, gender and location. This is the only free demographic targeting signal available and the pull should capture it when present. Verify the current layout on a live ad.
- **Terms:** Meta's platform terms on automated access to the Ad Library web UI were not readable from the pages fetched. The plugin's `LEGAL-AND-ETHICS.md` must say that automated access may be restricted by platform terms, that the member runs read-only research on their own machine, and that Apify and manual routes exist.
- **Third-party scrapers (vendor, Apify store listings):** prices per 1,000 ads ranged from $0.29 to $4.00 depending on the actor, with compute billed separately on some. Pricing changes; the tool must read the actor's listed price at run time and print it.

Sources: [Meta Transparency Center ad library tools](https://transparency.meta.com/researchtools/ad-library-tools/), [adlibrary.com API guide](https://adlibrary.com/guides/facebook-ad-library-api), [adlibrary.com API limitations](https://adlibrary.com/posts/meta-ad-library-api-limitations), [Swipekit on the API](https://swipekit.app/articles/meta-ad-library-api), [Admapix developer guide](https://www.admapix.com/blog/ad-intelligence/meta-ads-library-api-developers), [Ryze on the API](https://www.get-ryze.ai/blog/meta-ads-library-api), [HyperFX scraper guide](https://www.hyperfx.ai/blog/meta-ad-library-api-scraper-guide), Apify actors: [curious_coder](https://apify.com/curious_coder/facebook-ads-library-scraper), [valev-lab](https://apify.com/valev-lab/facebook-ads-library), [magnolia_yont](https://apify.com/magnolia_yont/meta-facebook-ads-library-scraper-realfast.md), [bovi](https://apify.com/bovi/meta-ads-library-scraper), [sleeze22](https://apify.com/sleeze22/facebook-ads-library-scraper-pro).

### TikTok

- **Commercial Content Library** (library.tiktok.com): public, no login, but only ads shown in the EEA, Switzerland and the UK (vendor sources say 33 markets, one adds Turkey). Jared's probe confirmed it loads without login; "Skool" returned only Vans ads. There is a research-credentialed Commercial Content API; a broader 2026 Research API expansion was reported but not confirmed.
- **Creative Center Top Ads**: a curated gallery of advertiser-authorized high performers, not an archive; loads without login as a category dashboard; brand-specific search and ad details need login. No public API. Vendor guides cite a roughly six-month window.
- Design consequence: TikTok is an assisted flow (the skill drives the member's own browser) plus the CCL script for EU coverage.

Sources: [Top Growth Marketing guide](https://topgrowthmarketing.com/tiktok-ads-library/), [Selzee](https://selzee.com/tiktok-ads-library), [adlibrary.com Creative Center guide](https://adlibrary.com/posts/tiktok-creative-center-guide), [adlibrary.com TikTok ad library](https://adlibrary.com/posts/tiktok-ad-library), [Stackmatix](https://www.stackmatix.com/blog/tiktok-creative-center-guide), [Admapix TikTok](https://www.admapix.com/blog/ad-intelligence/tiktok-ad-library-explained), [Admapix Creative Center](https://www.admapix.com/blog/ad-intelligence/tiktok-creative-center-tutorial), Apify: [topapi](https://apify.com/topapi/tiktok-ads-library-scraper), [lentic_clockss](https://apify.com/lentic_clockss/tiktok-ads-top-ads-actor/api).

### Google Ads Transparency Center and LinkedIn Ad Library

- **Google:** searchable by advertiser; shows text, image and video (YouTube) ads with regions and date ranges. No general public API; EEA ads have DSA-driven access; political ads are a public BigQuery dataset. SerpApi and SearchAPI sell scraped endpoints. Retention figures in vendor sources conflict (30 days to 13 months), so do not rely on them. This is the best free source for competitor **video** ads because it links the YouTube creative.
- **LinkedIn:** public browse at linkedin.com/ad-library, no public API, Marketing API covers only your own account. Useful for B2B members only.

Sources: [Apify Google transparency actor](https://apify.com/sauliusautomatesit/google-ads-transparency-api), [adlibrary.com platform comparison](https://adlibrary.com/posts/ad-transparency-data-landscape), [SerpApi](https://serpapi.com/google-ads-transparency-center-api), [SearchAPI](https://www.searchapi.io/google-ads-transparency-center-api), [Admapix Google guide](https://www.admapix.com/blog/ad-intelligence/google-ads-transparency-center-guide), [adlibrary.com Google API](https://adlibrary.com/posts/google-ads-transparency-center-api), [AdMake guide](https://admakeai.com/blog/google-ads-transparency-center), [adlibrary.com LinkedIn 2026](https://adlibrary.com/posts/linkedin-ad-library-2026), [Admapix LinkedIn](https://www.admapix.com/blog/ad-intelligence/linkedin-ads-library).

### Competitor discovery

Free web tools (Switas, ChampSignal) and trial APIs (Klazify, NinjaPear, Zyla) exist; a Relevance AI template scrapes the target site, generates keywords and searches each. None was verified for pricing or quality. Ad Lab should not depend on any of them; the researcher agent uses search, directories, review sites, community threads and Ad Library keyword searches on the category's language, which is free and more revealing (advertisers who use your words compete for your attention).

## 2. Claude Code packaging (official docs, read October 22, 2026)

- Skills: `skills/<name>/SKILL.md`, frontmatter on line 1; fields include `name`, `description`, `when_to_use`, `argument-hint`, `arguments`, `disable-model-invocation`, `user-invocable`, `allowed-tools`, `disallowed-tools`, `model`, `effort` (low, medium, high, xhigh, max), `context: fork`, `agent`, `background`, `hooks`, `paths`, `shell`, `metadata`. `$ARGUMENTS`, `$0`, named `$name`. Variables `${CLAUDE_SKILL_DIR}`, `${CLAUDE_PROJECT_DIR}`, `${CLAUDE_PLUGIN_ROOT}`, `${CLAUDE_PLUGIN_DATA}`. Scripts run through `Bash(...)` pre-approval. Keep under 500 lines.
- Plugins: only the manifest lives in `.claude-plugin/`; `plugin.json` needs only `name`; `version` controls cache refresh for hosted users; components namespaced `/<plugin>:<skill>`; a root `CLAUDE.md` is not loaded; `bin/` blocks claude.ai and Cowork installs.
- Subagents: `agents/<name>.md`; required `name` and `description`; `tools`, `model` (sonnet, opus, haiku, fable, inherit), `skills` preload, `effort`, `maxTurns`; plugin subagents ignore `hooks`, `mcpServers`, `permissionMode`.
- Marketplaces: `.claude-plugin/marketplace.json` with `name`, `owner.name`, `plugins[]` each with `name` and `source`; a single-plugin repo uses `"source": "./"`. Install: `/plugin marketplace add owner/repo` then `/plugin install plugin@marketplace`, or one step with `--marketplace`; desktop app has an Add plugins button. Validate with `claude plugin validate`; test with `claude --plugin-dir`.

Sources: [skills](https://code.claude.com/docs/en/skills), [plugins](https://code.claude.com/docs/en/plugins), [sub-agents](https://code.claude.com/docs/en/sub-agents), [plugin marketplaces](https://code.claude.com/docs/en/plugin-marketplaces), [manifest reference](https://code.claude.com/docs/en/plugins/manifest-reference), [marketplace reference](https://code.claude.com/docs/en/plugins/marketplace-reference), [install](https://code.claude.com/docs/en/plugins/install), [publish](https://code.claude.com/docs/en/plugins/publish).

## 3. Opus 5.5 settings and prompting (official docs)

- Effort levels: `low, medium, high, xhigh, max`; Opus 5.5 defaults to `medium` (Opus 5 defaulted to `high`). `xhigh` is described for long-running agentic and coding tasks over 30 minutes with multi-million-token budgets; `max` has no spending constraint; Anthropic says to reserve both for measured gains. There is no official level called "extra" or "very high"; a reviewer's "very high" is `xhigh`.
- Thinking is always on and adaptive on 5.5 and cannot be disabled; control depth with effort, not prompt wording. Do not ask the model to write its reasoning into replies.
- For unattended long work: keep a checklist the model updates; state the completion condition; if it stops early send one short message naming the open items; stop after two or three nudges. Status notes belong in the same message as the next tool call. Give a time budget line. For frontend work, name the specific default styles to avoid.
- Per-message effort changes keep the prompt cache; changing top-level effort between requests restarts it.

Sources: [prompting Opus 5.5](https://platform.claude.com/docs/en/build-with-claude/prompt-engineering/prompting-claude-opus-5-5), [effort](https://platform.claude.com/docs/en/build-with-claude/effort), [thinking](https://platform.claude.com/docs/en/build-with-claude/thinking), [what's new in Opus 5](https://platform.claude.com/docs/en/models/opus-5/whats-new-opus-5).

## 4. Higgsfield API (official blog and docs, read October 22, 2026)

- Console at console.higgsfield.ai; key id plus secret, shown once; base `https://api.higgsfield.ai`; header `Authorization: Key <id>:<secret>`; send an `Idempotency-Key` on submits; 20 concurrent requests on a new key.
- Always asynchronous: submit returns `request_id`, `status_url`, `cancel_url`; poll `GET /requests/{id}/status` until `completed`, `failed`, `nsfw` or `canceled`; outputs as `images[].url` or `video.url`; files kept at least seven days, so download.
- Confirmed endpoint: `POST /higgsfield-ai/soul/v2/standard` with `{"prompt": "..."}`. Per-model endpoints for image-to-video and text-to-video exist but were not read; Opus must read the model pages before hard-coding them.
- Python: `pip install higgsfield-client`; `higgsfield_client.subscribe("higgsfield-ai/soul/v2/standard", arguments={"prompt": "..."})`.
- Pricing: prepaid USD balance, billed per successful generation; blog starting rates, for example Soul 2 at $0.0032 per image, Kling 2.6 at $0.07 per second, Kling 3.0 at $0.112 per second; the pricing page was not read, so the tool keeps a price table the member can update and prints the estimate before each run.
- A member's own account rules apply to their runs: a credit floor they set, every run logged, nothing synthetic of a real person without written consent.

Sources: [Higgsfield API blog](https://higgsfield.ai/blog/higgsfield-api), [generate videos from the API](https://higgsfield.ai/blog/generate-ai-videos-higgsfield-api), [docs quickstart](https://docs.higgsfield.ai/docs/quickstart.md), [requests](https://docs.higgsfield.ai/docs/concepts/requests.md), [SDK](https://docs.higgsfield.ai/docs/how-to/sdk.md), [video models](https://docs.higgsfield.ai/docs/models/video-generation.md), [image models](https://docs.higgsfield.ai/docs/models/image-generation.md), third-party: [apiframe guide](https://apiframe.ai/guides/higgsfield-api-guide), [entarabi on the September 2026 launch](https://entarabi.com/en/2026/09/higgsfield-expands-developer-access-with-apis-and-github-tools/).
