# Lesson 1: install and your first run (8 minutes)

**Screen:** Claude Code open in an empty folder named after your business.

1. Say what Ad Lab is in one breath: it reads the public ad libraries, decodes what your competitors are doing and to whom, grills your business, and writes your ads with the reasoning shown. It never touches your ad account and never invents proof.
2. Type the two install commands from INSTALL.md. Show the plugin appearing.
3. `/adlab:setup`. While Chromium downloads, explain Full mode versus Lite mode: if Python is a pain on your machine, skip setup and paste links instead.
4. `/adlab:start`. Show the folder tree it created and PROGRESS.md. Say: you can close this any time and resume from the first step that is not done.
5. Paste your website. Watch intake read it and come back with the first six questions, each with a default. Answer two honestly, accept the rest, and say you will come back to them.
6. End: the brief it wrote, with every line labeled observed, owner-provided or inferred.
