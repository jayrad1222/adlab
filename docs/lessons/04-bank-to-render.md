# Lesson 4: from the bank to a file you can upload (10 minutes)

**Screen:** bank/ad-bank.html, then a rendered static.

1. Open the board. Filter by persona, then by status. Read one entry: the hook, the three text lengths, the headline, the CTA, the why, the competitor references, the critic's note.
2. Harry Dry's three tests on one line: can you visualize it, can you falsify it, could nobody else say it. Delete a line that fails live.
3. Assets: drop five real files into assets/ and run the catalog. Show the three columns (your note, Claude's read, revised read) and the consent column. Say: no consent, no use.
4. Render one static at 4:5 and 9:16. Show the legibility check at phone width and the safe zone. One real moment fills the frame; the words are the hook, the offer line and the wordmark.
5. Storyboard for one video concept: six frames, a brief for a shoot, not an ad.
6. If you use Higgsfield: show the price printed before the run and the refusal when a prompt asks for something that would read as proof.
